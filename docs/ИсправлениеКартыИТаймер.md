# 🃏 Исправление: карты, спектатор, таймер

> Дата: 08.06.2026

---

## Проблемы

### 1. «You are spectating» у всех игроков
**Причина:** `player.id` в `GameStateView.players` — это DB-ный числовой ID (`"1"`, `"2"`), а `username` из AuthContext — это логин (`"alex"`, `"bob"`). Сравнение `player.id === username` всегда было `false`.

**Исправление:** сопоставление через `seatIndex`. Находим свой `seatIndex` из `table.seats` (где `username` совпадает), затем ищем игрока в `players` по `seatIndex`.

### 2. Карты мерцают / не показываются
**Причина:** та же — `myPlayer` не находился → `player.holeCards` не отображались для «себя». В `PlayerSeat` передавалось `isMe={false}` для всех.

**Исправление:** `isMe={player.seatIndex === mySeatIdx}`.

### 3. Нет таймера на ход
**Причина:** таймер не был реализован ни на фронте, ни на бэкенде.

**Исправление:**
- Добавлен `timeLeft` (state) и `timerRef` (setInterval)
- При `actions.yourTurn === true` запускается обратный отсчёт от `timeoutSecs`
- При ≤ 5 секунд — цифры красные и мигают
- При 0 — автоматический **FOLD**
- Таймер сбрасывается при смене хода (`currentIdx`)
