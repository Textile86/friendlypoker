# 🃏 Исправление: карты (★), мерцание, таймаут → SIT OUT

> Дата: 08.06.2026

---

## Проблемы

### 1. Звёздочки (★) вместо карт
**Причина:** `GameService.startHand()` вызывает `GameStateView.from(tableId, result.newState(), null)` — передаёт `null` вместо `viewerPlayerId`. Из-за этого `(isViewer || showdown)` всегда `false`, и `holeCards` возвращается пустым списком.

**Исправление (бэкенд — ты):** В `GameService.java`, строка 144:
```java
// БЫЛО:
return GameStateView.from(tableId, result.newState(), null);

// СТАЛО:
return GameStateView.from(tableId, result.newState(), caller.getId().toString());
```

### 2. Мерцание карт
**Причина:** `broadcast()` в GameService тоже передаёт `null` как viewer → WebSocket-рассылка возвращает состояние без holeCards → перезаписывает локальное состояние с картами.

**Исправление (фронтенд):** WebSocket-колбэк в `GamePage.tsx` теперь сохраняет `holeCards` из предыдущего состояния для локального игрока.

### 3. Таймаут → авто-FOLD + SIT OUT
**Причина:** При истечении таймера фронтенд отправляет FOLD на бэкенд, но статус игрока становится `FOLDED` (на одну раздачу), а не `SITTING_OUT` (пропуск раздач пока не вернётся).

**Исправление (фронтенд):** Добавлен локальный стейт `sittingOut`. После авто-FOLD по таймауту игрок помечается как SIT OUT — его карты не раздаются, иконка бледнеет, показывается метка «SIT OUT».

**Исправление (бэкенд — ты, опционально):** В будущем можно сделать полноценный SIT_OUT на бэкенде — после таймаут-фолда помечать игрока как `SITTING_OUT` в движке, чтобы в следующих раздачах ему не сдавались карты и он пропускал ход. Сейчас это работает визуально на фронтенде.
