# Удали все данные (порядок важен — от дочерних таблиц к родительским)

1. **http://localhost:5173/register**

## 5. Тестирование: лобби и столы (браузер)

### 5.1 Создать клуб (alex)

1. В первом браузере (alex) на главной `/`
2. В секции **«Клубы»** нажми **«+ New Club»**
3. Название: `Пятничный покер` → **Create**

### 5.2 Пригласить bob в клуб

1. Зайди в клуб «Пятничный покер» (кликни по нему)
2. Нажми **«Generate Invite»** → скопируй код

### 5.3 Принять инвайт (bob)

1. Во втором браузере (bob) на главной `/`
2. В секции «Join by Invite» вставь код → **Join**

**Ожидаемый результат:** bob видит клуб «Пятничный покер» в своём списке.

### 5.4 Создать стол (alex)

1. В браузере alex зайди в клуб «Пятничный покер»
2. Нажми **«+ New Table»**
3. Заполни:
   - **Table name:** `Пятничная игра`
   - **Small Blind:** `5`
   - **Big Blind:** `10`
   - **Max Players:** `6`
   - **Starting Chips:** `1000`
   - **Action Timeout (sec):** `30`
4. Нажми **«Create Table»**

**Ожидаемый результат:** стол появляется в списке со статусом WAITING.

### 5.5 Сесть за стол (bob)

1. Во втором браузере (bob) зайди в клуб
2. Нажми **«Sit Down»** у стола «Пятничная игра»

**Ожидаемый результат:** кнопка меняется на «▶ Play» и «Stand Up».

### 5.6 Сесть за стол (alex)

1. В первом браузере (alex) нажми **«Sit Down»** у стола

### 5.7 Войти за стол (оба)

1. alex нажимает **«▶ Play»**
2. bob нажимает **«▶ Play»**

**Ожидаемый результат на `/game/1`:**
- Зелёный овальный фетр
- Два игрока отображаются: alex (синяя рамка) и bob (серая рамка)
- У каждого: имя, chips (1000)
- Метка **«Live»** (зелёная)
- У **alex** (Owner) видна кнопка **«▶ Start Hand»**

## 6. Тестирование: игровой процесс (браузер)

> ⚠️ **Важно:** кнопка **«▶ Start Hand»** появляется только у **Owner** или **Admin** клуба.  
> alex — Owner (создатель клуба), bob — Member. Start Hand должен нажимать **alex**.

### 6.1 Запустить раздачу

**alex** нажимает **«▶ Start Hand»**.

**Что должно произойти на экране:**
- Фаза в центре стола: **PRE FLOP**
- У каждого игрока появляются **2 карты** (чужие — рубашкой ★)
- Свои карты видны лицом (например: `A♠ K♥`)
- Надпись **«Pot: 15»** (SB=5 + BB=10)
- Один игрок подсвечен **жёлтой рамкой с пульсацией** — его ход
- Внизу панель действий: **Fold**, **Call 10**, **Raise**, **All-In**
- У второго игрока: «Waiting for opponent…»

### 6.2 Сделать ход (префлоп)

1. Игрок с жёлтой рамкой → **Call 10**
2. Ход переходит ко второму → **Call 10** (или Check)

**Ожидаемый результат:**
- Фаза → **FLOP**
- В центре стола 3 общие карты
- Pot обновлён (20)

### 6.3 Доиграть до шоудауна

Продолжай Check/Call на флопе, тёрне, ривере:

| Фаза | Что видно на столе |
|---|---|
| FLOP | 3 общие карты |
| TURN | 4 общие карты |
| RIVER | 5 общих карт |
| SHOWDOWN | Карты открыты лицом, победитель подсвечен |

**Ожидаемый результат:**
- Банк переходит победителю (chips увеличиваются)
- Фаза → **FINISHED**
- Кнопка **«▶ Start Hand»** снова доступна (у alex)

### 6.4 Кнопки действий

| Кнопка | Цвет | Что происходит |
|---|---|---|
| **Fold** | Красный | Игрок падает, opacity 40%, ход переходит |
| **Call / Check** | Синий | Уравнивает (Call) или пропускает (Check) |
| **Raise** | Зелёный | Слайдер выбора суммы → кнопка «Raise → N» |
| **All-In** | Фиолетовый | Все фишки в банк |

### 6.5 Слайдер рейза

При нажатии **Raise**:
- Под кнопками — ползунок (range slider)
- Минимум: 2× предыдущая ставка
- Максимум: все фишки
- Надпись: «Raise to: **N**»

## 9. Типичные проблемы

| Что видно в браузере | Вероятная причина | Что делать |
|---|---|---|
| **Белый экран после регистрации** | Ошибка JS | F12 → Console |
| **«Could not load table»** | Бэкенд не запущен | `docker compose ps` |
| **«Connecting…» (красная)** | WebSocket не подключён | Проверь бэкенд на 8080 |
| **Нет кнопки Start Hand** | Ты — Member, а не Owner | Start Hand только у alex (Owner) |
| **Кнопки действий не появляются** | Не твой ход | Жди жёлтой рамки |
| **«Start Hand» не активна** | < 2 игроков за столом | Проверь, что оба игрока нажали «Sit Down» |
| **После логина белый экран** | JWT ошибка | F12 → Network → `/api/me` |
| **Карты не отображаются** | Игра не начата | Нажми «Start Hand» (alex) |
| **Страница не обновляется** | WebSocket отвалился | F5 |

## 11. Что пока НЕ работает (ожидаемые ограничения)

| Ограничение | Почему |
|---|---|
| **Только Холдем** (2 карты) | Движок захардкожен на 2 карты |
| **Нет выбора игры** при создании стола | UI не отправляет `gameVariant` |
| **Нет PWA** (не установить на телефон) | Нет `manifest.json` и service worker |
| **Плохо на мобильном** | UI не адаптирован под телефоны |
| **Нужно минимум 2 игрока** для старта | Валидация в движке |
| **Start Hand только у Owner/Admin** | Ограничение `GameService.startHand()` |
